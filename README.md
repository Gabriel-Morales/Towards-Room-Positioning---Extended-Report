# Towards-Room-Positioning---Extended-Report
This repository contains the extended report and other stuff related to our workshop paper, "Towards Achieving Room-Level Localization Fusing Depth-Based and Spectrographic Modalities".
This work is a proof-of-concept and exploratory research to see how we can incorporate fusion with some extra data / grounded modalities to help perform room-localization (positioning classification) with spectrograms.

I chose a repository since I can update it at any time with more details and data :)


For now, the repository only contains the initial extended report. However, over time and probably soon I will add an archived version of the longer paper since we had to reduce the size to fit workshop constraints.


* Original Averages: This file is the original averages composed of all ten sessions for each room in the pre-condensed version. To see all non-averaged data, look at the extended report.
